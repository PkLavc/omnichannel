Onde cadastrar as API keys

Você está em Admin → IA e providers / chaves. Na tabela “Providers e fallback”:

  1. Marque o provider como Habilitado e defina a prioridade — o menor número responde primeiro.
  2. Confira modelo e Base URL, informe a chave no campo API key e clique em Salvar.
  3. Clique em Testar e confirme que a saúde ficou “saudável”.

Cloudflare AI: além do token, informe a Base URL https://api.cloudflare.com/client/v4/accounts/SEU_ACCOUNT_ID/ai/v1, substituindo SEU_ACCOUNT_ID pelo Account ID exibido no dashboard Cloudflare. O token deve ter permissões Workers AI Read e Workers AI Edit.

Persistência e segurança: as chaves são cifradas pelo Gateway e gravadas no PostgreSQL persistente. Elas sobrevivem a reinícios dos containers; mantenha a GATEWAY_ENCRYPTION_KEY estável e faça backup do banco. Nunca coloque chaves de providers no Cloudflare Pages, em JavaScript/frontend, no Git ou em arquivos publicados. Depois de salvar, a chave não é exibida novamente.

Conhecimento / RAG

Documentos, chunks e embeddings indexados no pgvector.

Como indexar a planilha inicial

Você está em Admin → Conhecimento / RAG. Clique em escolher arquivo, selecione data/rag/respostas_rapidas.xlsx dentro do projeto e depois clique em Importar e indexar. Quando concluir, confirme abaixo que o documento está com status ready e que possui chunks e embeddings.

A indexação é persistida no PostgreSQL/pgvector e continua disponível após reiniciar os containers. O mesmo conhecimento recuperado é enviado ao provider principal ou ao provider de fallback; não é necessário importar uma cópia para cada IA.

Importar documento

Formatos: XLSX, PDF, DOCX, Markdown, TXT e HTML. Limite de 25 MB.

Aprendizado autônomo com aprovação enxuta

O Gateway consolida muitas conversas em poucos candidatos de comportamento. Repetição não é tratada como verdade: são exigidos clientes distintos, resultados verificados, baixa contradição e confiança mínima. Preço, desconto, garantia e política nunca são aprendidos do texto das conversas; permanecem bloqueados até existir RAG, regra ou Tool oficial.

Abra esta seção para carregar as métricas.

Candidatos consolidados

Revise cards agregados, não respostas temporárias. Uma aprovação aplica apenas a tática segura; fatos comerciais continuam obrigatoriamente consultados em fontes atuais.
